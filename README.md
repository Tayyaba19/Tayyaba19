`AWS Bedrock` `Lambda` `S3` `OpenSearch` `Knowledge Bases` `Python`

`Neo4j` `LangChain` `OpenAI` `MCP` `Docker` `CI/CD`

`OpenAI` `Whisper` `LangChain` `WhatsApp API` `Vertex AI` `Dialogflow`
